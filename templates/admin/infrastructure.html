Load Balancing & Traffic Distribution Strategy

VKShop uses Latency-Aware Weighted Routing to automatically distribute traffic across healthy backend servers while bypassing failing nodes.

502 Prevention & Automatic Failover Circuit Breaker
  • Consecutive Failure Threshold: 3 health check failures trigger immediate server removal from traffic pool.
  • Auto Recovery: When an unhealthy server passes readiness checks, it enters warm-up and is re-added to active routing pool.
  • Stateless Architecture: All sessions and carts are stored in Redis / PostgreSQL, so user traffic transfers seamlessly.
